# Skills IA

Colección modular de habilidades para asistentes de inteligencia artificial. Cada módulo es independiente, cuenta con herramientas basadas en la biblioteca estándar de Python y sigue una arquitectura unificada.

[English Version](README.en.md)

---

## Módulos incluidos

| Carpeta | Propósito |
| :--- | :--- |
| **`agent-red-team`** | Auditoría estática de seguridad y detección de inyecciones en instrucciones. |
| **`humanizador-anti-ia`** | Reescritura estilística para incrementar variabilidad rítmica y léxica. |
| **`replica`** | Especificación y reconstrucción funcional limpia de aplicaciones complejas. |
| **`seo-auditor`** | Auditoría técnica, semántica y estructural para proyectos web y repositorios. |

---

## Arquitectura de cada módulo

Cada habilidad contiene:
- `SKILL.md`: Instrucciones y reglas de activación.
- `references/`: Guías de conocimiento técnico.
- `scripts/`: Herramientas ejecutables en Python estándar (sin dependencias externas).
- `templates/`: Plantillas para estructurar los resultados.
