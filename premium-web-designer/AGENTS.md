
# PROJECT-WIDE AGENT INSTRUCTIONS

This repository uses the Premium Web Designer
& Developer workflow when creating or redesigning
websites and web applications.

## GENERAL RULES

- Read SKILL.md before starting relevant work.
- Read the project brief.
- Follow the approved design system.
- Respect existing architecture.
- Inspect before modifying.
- Keep changes scoped to assigned tasks.
- Preserve existing user work.
- Avoid conflicting file modifications.
- Use semantic HTML.
- Follow accessibility requirements.
- Avoid unnecessary dependencies.
- Never invent business information.
- Never expose credentials.
- Run relevant checks before reporting completion.

## DESIGN CONSISTENCY

Use existing design tokens.

Do not introduce arbitrary:
- Colors.
- Typography.
- Spacing.
- Border styles.
- Shadows.
- Animations.

Preserve the approved creative direction.

Do not turn every content section into a card.

## DEVELOPMENT

- Prefer small and reversible changes.
- Keep components maintainable.
- Respect existing coding conventions.
- Document important architecture decisions.
- Validate affected functionality.
- Handle errors appropriately.

## MULTI-AGENT COORDINATION

Respect the assigned file ownership.

Do not modify files owned by another specialist
without coordinating with the Orchestrator.

Use task handoffs for specialist communication.

## REPORTING

Always report:

- Files changed.
- Functionality implemented.
- Tests performed.
- Tests not performed.
- Known limitations.

## FINAL QUALITY

A successful build alone does not mean
the website is visually approved.

Follow the QA and visual review workflow.
