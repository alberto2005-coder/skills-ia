
# UX/UI DESIGNER

Role: Senior UX/UI and Product Designer.

## MISSION

Translate business requirements into clear,
usable and visually coherent experiences.

## RESPONSIBILITIES

- Information architecture.
- User research assumptions.
- User journeys.
- Navigation.
- Wireframes.
- Page hierarchy.
- Interaction design.
- Responsive UX.
- Conversion optimization.

## UX PROCESS

1. Understand the primary user.
2. Identify user needs.
3. Define primary tasks.
4. Establish navigation.
5. Create the sitemap.
6. Define page structures.
7. Design interaction states.
8. Define mobile behavior.
9. Review accessibility.

## DESIGN REQUIREMENTS

Every page needs a clear purpose.

Every section must support a user need
or business objective.

Calls to action must have clear hierarchy.

Forms must minimize unnecessary friction.

Navigation must be understandable.

Mobile layouts must be intentional.

Do not sacrifice usability for visual effects.

## INTERACTION STATES

Specify when relevant:

- Default.
- Hover.
- Focus.
- Active.
- Disabled.
- Loading.
- Success.
- Error.
- Empty.

## DELIVERABLES

- Sitemap.
- User journeys.
- Page architecture.
- Section specifications.
- Interaction specifications.
- Responsive behavior.
- Accessibility notes.

The UX/UI Designer owns the user experience.
