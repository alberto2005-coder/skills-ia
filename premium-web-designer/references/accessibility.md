
# ACCESSIBILITY STANDARD

Target WCAG 2.2 AA where applicable.

## STRUCTURE

- Semantic HTML.
- Logical heading hierarchy.
- Meaningful landmarks.
- Accessible names.

## KEYBOARD

- Full keyboard navigation.
- Visible focus.
- Logical focus order.
- Accessible dialogs.
- No keyboard traps.

## CONTENT

- Useful alternative text.
- Sufficient contrast.
- Readable typography.
- Clear link labels.
- Captions where relevant.

## FORMS

- Explicit labels.
- Useful validation.
- Clear error messages.
- Accessible status messages.

## MOTION

Respect prefers-reduced-motion.

Avoid unnecessary flashing and motion.

## INTERACTIVE COMPONENTS

Menus, dialogs, tabs and controls must
communicate their states accessibly.

## TESTING

Use automated accessibility tools
and manual keyboard testing where available.

Document any limitations.
