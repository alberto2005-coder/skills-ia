
# PERFORMANCE AND SEO STANDARD

## PERFORMANCE

- Optimize image formats and dimensions.
- Lazy-load non-critical images.
- Avoid unnecessary JavaScript.
- Reduce layout shifts.
- Optimize font loading.
- Minimize unnecessary third-party scripts.
- Use caching appropriately.
- Measure actual performance.

## SEO

Implement when relevant:

- Unique page titles.
- Meta descriptions.
- Semantic HTML.
- Logical headings.
- Canonical URLs.
- Sitemap.
- Robots directives.
- Open Graph metadata.
- Descriptive internal links.
- Image alternatives.
- Accurate structured data.

## CONTENT

Avoid:
- Duplicate page titles.
- Empty metadata.
- Keyword stuffing.
- Misleading structured data.
- Automatically generated meaningless copy.

## VERIFICATION

Use available:
- Lighthouse.
- Browser audits.
- Search engine inspection tools.
- Build checks.

Never invent performance scores
or indexing results.
