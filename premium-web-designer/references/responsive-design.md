
# RESPONSIVE DESIGN STANDARD

## GENERAL PRINCIPLES

Use content-driven responsive layouts.

Avoid unnecessary fixed dimensions.

Prevent horizontal overflow.

Use fluid typography where appropriate.

Optimize images for different screens.

## MOBILE

Review:

- Navigation.
- Reading order.
- Content density.
- Typography.
- Touch targets.
- Forms.
- Image crops.
- Sticky elements.
- Interactive components.

Do not simply compress desktop layouts.

## TABLET

Reconsider:

- Column counts.
- Navigation.
- Grid structure.
- Typography.
- Spacing.
- Image positioning.

## DESKTOP

Consider:

- Maximum content width.
- Long text lines.
- Large-screen composition.
- Visual balance.
- Navigation behavior.

## MINIMUM VIEWPORT TESTS

360px.
390px.
768px.
1024px.
1440px.

Test intermediate widths when possible.

## ACCEPTANCE

No unintended horizontal overflow.

No unreadable text.

No broken navigation.

No inaccessible interactive elements.

No major visual inconsistencies.
