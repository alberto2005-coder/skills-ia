
# VISUAL QUALITY STANDARD

## OBJECTIVE

Prevent generic and repetitive visual output.

## ANTI-PATTERNS

Review for:

- Generic AI-style hero sections.
- Excessive gradients.
- Unnecessary glow effects.
- Repetitive card grids.
- Excessive rounded containers.
- Random decorative shapes.
- Unmotivated glassmorphism.
- Generic marketing copy.
- Repetitive stock photography.
- Inconsistent spacing.
- Weak typography.
- Unnecessary animations.

These techniques are not universally forbidden.
They must have a clear creative justification.

## COMPOSITION, VISUAL HIERARCHY, AND IMAGERY

- Composition should create balance, focus and a clear visual rhythm.
- Visual hierarchy should make the primary action and key content easy to scan.
- Imagery should be relevant, intentional and consistent with the brand.

## QUALITY QUESTIONS

1. Does the website have a recognizable identity?
2. Does the design suit the business?
3. Is the hierarchy clear?
4. Does each section have a purpose?
5. Is there visual rhythm?
6. Is typography intentional?
7. Are images relevant?
8. Are interactions polished?
9. Does mobile feel carefully designed?
10. Does the website feel coherent as a whole?

## VISUAL AUDIT PROCESS

1. Inspect the actual rendered website.
2. Review important pages.
3. Review different screen widths.
4. Identify the three most important issues.
5. Assign corrective tasks.
6. Implement changes.
7. Reinspect the result.

## IMPORTANT

Do not claim visual approval without
actual visual inspection.

If screenshots or browser access are unavailable,
document the limitation.
