
# DELIVERY WORKFLOW

## OBJECTIVE

Deliver a complete, understandable
and maintainable project.

## FINAL CHECKLIST

### DESIGN
- [ ] Approved visual direction implemented.
- [ ] Consistent design system.
- [ ] Correct typography.
- [ ] Appropriate imagery.
- [ ] Responsive layouts.

### FUNCTIONALITY
- [ ] Navigation works.
- [ ] Links work.
- [ ] Forms work.
- [ ] Interactions work.
- [ ] Required integrations verified.

### QUALITY
- [ ] Accessibility reviewed.
- [ ] SEO fundamentals implemented.
- [ ] Performance reviewed.
- [ ] Build verified.
- [ ] Critical issues resolved.

### DOCUMENTATION
- [ ] Installation instructions.
- [ ] Environment variables documented.
- [ ] Development instructions.
- [ ] Deployment requirements.
- [ ] Known limitations documented.

## FINAL REPORT

Provide:

1. Project summary.
2. Pages completed.
3. Functionality implemented.
4. Technologies used.
5. Files changed.
6. Tests performed.
7. Outstanding issues.
8. Launch instructions.

## HONESTY

Distinguish between:
- Implemented.
- Tested.
- Verified.
- Not tested.
- Not implemented.

Do not report production readiness
without checking the relevant requirements.
