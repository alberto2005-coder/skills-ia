
# REVIEW AND ITERATION WORKFLOW

## OBJECTIVE

Improve the actual implementation through
independent inspection and corrective iterations.

## PROCESS

### 1. Initial inspection

Inspect the rendered website when possible.

Review:

- Homepage.
- Important internal pages.
- Navigation.
- Key interactions.
- Mobile layouts.

### 2. Visual audit

Identify:

- Inconsistent typography.
- Poor spacing.
- Weak hierarchy.
- Repetitive layouts.
- Incorrect image crops.
- Inconsistent components.
- Unnecessary decoration.
- Broken responsive compositions.

### 3. Functional audit

Test important user journeys.

Verify actual behavior.

### 4. Technical audit

Review:

- Console.
- Build.
- Accessibility.
- SEO.
- Performance.
- Errors.

### 5. Prioritization

Classify findings by severity.

Fix critical and high-priority problems first.

### 6. Correction

Assign findings to the responsible specialist.

Avoid overlapping file modifications.

### 7. Retesting

Repeat the relevant checks.

Update the QA report.

## ITERATION STANDARD

Focus on the three most important problems
in each review cycle.

Do not endlessly polish insignificant details.

## FINAL CONDITION

The website must meet its documented
acceptance criteria.

Unverified areas must be disclosed.
